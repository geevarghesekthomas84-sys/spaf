### ◈ The intelligent core of modern offensive security.

**SPAF** is a professional-grade, asynchronous framework engineered for precision reconnaissance and automated vulnerability analysis. By synthesizing high-performance scanning modules with the cognitive capabilities of **Gemini**, **Claude**, and local LLMs (**Ollama/LM Studio**), SPAF transforms raw data into tactical offensive intelligence.

---

## ⚡ Core Capabilities

#### 🧠 **AI-Augmented Intelligence**
> Transform scan results into high-fidelity attack paths. SPAF automatically identifies bypass strategies and generates weaponized Proof-of-Concept (POC) exploits.

#### 🕵️ **Shadow Operations**
> Execute scans with full anonymity. Integrated **TOR** routing, proxy-chaining, and dynamic browser fingerprint rotation come standard.

#### 📡 **Advanced Reconnaissance**
> Multi-vector discovery engine covering subdomain enumeration, DNS audit, and automated CVE correlation via the NVD.

## 🚀 Quick Start

**1. Installation**
```bash
git clone https://github.com/geevarghesekthomas84-sys/spaf.git
cd spaf
pip install -r requirements.txt && pip install -e .
```

**2. Configuration**
```bash
spaf setup
```

---

## 💻 Operational Matrix

```bash
# Web Security Audit
spaf webscan https://target.com

# AI-Driven Deep Analysis
spaf analyze --id <scan_id>

# Automated Remediation Code
spaf remediate <finding_id> --format ansible
```
