## ⚡ Overview

**SPAF** is an elite, asynchronous offensive security framework designed for modern red teamers and security researchers. By integrating advanced **Large Language Models (LLMs)** with high-performance scanning modules, SPAF automates the transition from raw vulnerability discovery to actionable exploitation intelligence.

> [!IMPORTANT]
> SPAF is not just a scanner; it's an automated security brain that thinks like a Red Team Operator.

---

## 💎 Premium Features

### 🤖 **Cognitive Intelligence Suite**
*   **Deep Analysis**: Leverages Gemini 1.5 Pro & Claude 3.5 Sonnet for finding correlation.
*   **Auto-POC**: Generates functional, weaponized Python exploit scripts in seconds.
*   **Adaptive Remediation**: Get tailored Ansible, Terraform, and Bash fixes for every finding.

### 🕵️ **OpsSec & Stealth Engine**
*   **Shadow Routing**: Native TOR integration for anonymous scanning.
*   **Dynamic Fingerprinting**: Automated rotation of User-Agents and browser headers to bypass modern WAFs.
*   **Proxy Orchestration**: Seamless management of SOCKS5/HTTP proxy chains.

### 📡 **Multi-Vector Scanning**
*   **Recon Pro**: Passive & Active subdomain discovery using `crt.sh` and DNS brute-forcing.
*   **Network Pulse**: High-speed port scanning with automated CVE mapping via NVD.
*   **Web Guardian**: Deep audit of web headers, cookies, TLS/SSL, and sensitive paths.

## 🚀 Quick Installation

### 1️⃣ Clone the Repository
```bash
git clone https://github.com/geevarghesekthomas84-sys/spaf.git
cd spaf
```

### 2️⃣ Initialize Environment
```bash
python -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate
pip install -r requirements.txt
pip install -e .
```

### 3️⃣ Interactive Setup
```bash
spaf setup
```

## 💻 Operational Usage

| Action | Command |
| :--- | :--- |
| **Comprehensive Web Audit** | `spaf webscan https://example.com` |
| **AI Security Analysis** | `spaf analyze --id <scan_id>` |
| **Weaponized POC Generation** | `spaf poc <finding_id>` |
| **Continuous Shadow Watch** | `spaf watch example.com --interval 3600` |
| **Interactive AI Shell** | `spaf shell` |
